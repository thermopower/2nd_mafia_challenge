# Feature 008 - 코스 상세 페이지 QA 체크리스트

## 1. 페이지 접근 및 라우팅

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 카탈로그에서 코스 카드 클릭 | `/catalog/:courseId`로 라우팅 | 코스 상세 페이지 표시 | ⬜ |
| URL 직접 접근 | `/catalog/:courseId` 직접 입력 | 페이지 정상 로드 | ⬜ |
| 뒤로가기 버튼 클릭 | 카탈로그로 이동 | `/catalog` 페이지로 이동 | ⬜ |
| 존재하지 않는 코스 ID | 404 처리 | "코스를 찾을 수 없습니다" 메시지 | ⬜ |

## 2. 코스 정보 표시

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 정상 코스 조회 | 제목, 설명, 썸네일 표시 | 모든 정보 정확히 표시 | ⬜ |
| 썸네일 없는 코스 | placeholder 이미지 표시 | picsum.photos 기본 이미지 | ⬜ |
| 카테고리/난이도 표시 | Badge 컴포넌트로 표시 | 한글 라벨 정상 표시 | ⬜ |
| 강사 정보 표시 | 강사명 표시 | BookOpen 아이콘과 함께 표시 | ⬜ |
| 수강생 수 표시 | 실시간 enrollment count | Users 아이콘과 함께 표시 | ⬜ |
| 평균 평점 표시 | 모의 데이터 4.5/5.0 | 안내 문구와 함께 표시 | ⬜ |

|---------|----------|-----------|------|
| 비로그인 사용자 | 로그인 안내 메시지 | 파란색 안내 박스 표시 | ⬜ |

| 수강신청 성공 | 토스트 메시지 + 상태 갱신 | "수강신청 성공" 토스트 | ⬜ |

| 수강 취소 성공 | 토스트 메시지 + 상태 갱신 | "수강 취소 성공" 토스트 | ⬜ |
| 수강 취소 실패 | 에러 토스트 | 에러 메시지 표시 | ⬜ |
| draft 상태 코스 | 버튼 비활성화 | "수강신청 불가" 표시 | ⬜ |

## 5. 로딩 및 에러 처리

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 초기 로딩 | 스피너 표시 | Loader2 애니메이션 | ⬜ |

| 재시도 버튼 클릭 | refetch 실행 | API 재호출 | ⬜ |
| 401/403 에러 | 권한 에러 처리 | 적절한 안내 메시지 | ⬜ |
