# Feature 009 - 코스별 성적 상세 페이지 QA 체크리스트

## 1. 페이지 접근 및 권한

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 학습자 접근 | `/dashboard/courses/:courseId/grades` 접근 | 성적 페이지 정상 표시 | ⬜ |
| 강사 접근 | 강사 계정으로 접근 | "학습자만 조회 가능" 메시지 | ⬜ |
| 비로그인 접근 | 토큰 없이 접근 | 로그인 페이지로 리다이렉트 | ⬜ |
| 미등록 코스 접근 | 수강하지 않은 코스 | 403 에러 + 수강 신청 안내 | ⬜ |

## 2. 성적 요약 카드

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 정상 총점 표시 | 채점 완료된 과제 있음 | 총점 정확히 계산 표시 | ⬜ |
| 소수점 2자리 표시 | 총점 포맷 | 예: 87.50 / 100 | ⬜ |
| 채점 완료 수 표시 | 채점/전체 과제 수 | 예: 3 / 5 | ⬜ |
| 전체 가중치 표시 | 모든 과제 가중치 합 | 예: 100% | ⬜ |
| 부분 총점 배지 | 가중치 합 < 100 | "부분 총점" 배지 표시 | ⬜ |
| 부분 총점 안내 | 일부만 채점된 경우 | 노란색 안내 박스 표시 | ⬜ |
| 빈 상태 | 과제 0개 | 0 / 100, 0 / 0 표시 | ⬜ |

## 3. 과제별 성적 테이블

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 과제명 표시 | 제목 렌더링 | 과제 제목 정확히 표시 | ⬜ |
| 가중치 표시 | % 형식 | 예: 30% | ⬜ |
| 점수 표시 (채점 완료) | 점수 값 | 예: 85 | ⬜ |
| 점수 표시 (미채점) | null 처리 | "-" 표시 | ⬜ |
| 상태 배지 - graded | 채점 완료 상태 | 녹색 "채점 완료" 배지 | ⬜ |
| 상태 배지 - submitted | 제출됨 상태 | "평가 대기" 배지 | ⬜ |
| 상태 배지 - resubmission_required | 재제출 요청 상태 | 빨간색 "재제출 필요" 배지 | ⬜ |
| 상태 배지 - not_submitted | 미제출 상태 | 회색 "미제출" 배지 | ⬜ |
| 지각 배지 | late=true | 주황색 "지각" 배지 | ⬜ |
| 지각 제출 배지 | submitted + late | "지각 제출" 배지 (시계 아이콘) | ⬜ |
| 피드백 표시 | 피드백 있음 | 텍스트 표시 | ⬜ |
| 피드백 미리보기 | 100자 초과 | 2줄 line-clamp | ⬜ |
| 피드백 확장 | 더보기 버튼 클릭 | 전체 피드백 표시 | ⬜ |
| 피드백 접기 | 접기 버튼 클릭 | 미리보기로 축소 | ⬜ |
| 채점일 표시 | gradedAt 있음 | 한글 날짜 형식 (예: 2025년 10월 4일) | ⬜ |
| 피드백 없음 | feedback=null | "-" 표시 | ⬜ |

## 4. 총점 계산 로직

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 표준 계산 | 3과제, 모두 채점 | Σ(점수 × 가중치 / 100) | ⬜ |
| 부분 채점 | 일부만 채점 | 채점된 과제만 합산 | ⬜ |
| 가중치 합 100 미만 | 총 80% 가중치 | isPartialScore=true | ⬜ |
| 모든 과제 미채점 | 0개 채점 | 총점 0, isPartialScore=false | ⬜ |
| 소수점 반올림 | 87.456... | 87.46 표시 | ⬜ |

## 5. 로딩 및 에러 처리

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 초기 로딩 | 프로필 + 성적 로딩 | Loader2 스피너 | ⬜ |
| 네트워크 에러 | API 실패 | 에러 메시지 + 재시도 버튼 | ⬜ |
| 재시도 버튼 | 클릭 | refetch 실행 | ⬜ |
| 401 에러 | 인증 만료 | 에러 메시지 표시 | ⬜ |
| 403 에러 | 수강 미등록 | "수강 신청 필요" 메시지 | ⬜ |

## 6. 빈 상태 처리

|---------|----------|-----------|------|
| 과제 0개 | assignments=[] | "아직 과제가 등록되지 않았습니다" | ⬜ |
| 요약 카드 | 빈 상태 | 0 / 100, 0 / 0 표시 | ⬜ |

## 7. React Query 캐싱

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 캐시 키 | queryKey 생성 | ["course-grades", courseId] | ⬜ |
| staleTime | 3분 설정 | 3분 내 재방문 시 캐시 사용 | ⬜ |
| retry | 1회 설정 | 실패 시 1번만 재시도 | ⬜ |
| refetchOnWindowFocus | false 설정 | 포커스 복귀 시 refetch 안 함 | ⬜ |

## 8. 백엔드 API

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| GET /learner/courses/:courseId/grades | 정상 요청 | 200 + 성적 데이터 | ⬜ |
| 토큰 누락 | Authorization 헤더 없음 | 401 Unauthorized | ⬜ |
| 수강 미등록 | enrollment 없음 | 403 Forbidden | ⬜ |
| 잘못된 courseId | UUID 형식 아님 | 400/404 에러 | ⬜ |
| 스키마 검증 | 응답 파싱 | Zod 스키마 통과 | ⬜ |
