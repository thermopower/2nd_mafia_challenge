|---------|----------|-----------|------|

## 2. 폼 입력 및 검증

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 필수 필드 - 제목 | 빈 값 제출 | "제목은 필수입니다" 에러 | ⬜ |
| 필수 필드 - 설명 | 빈 값 제출 | "설명은 필수입니다" 에러 | ⬜ |
| 필수 필드 - 카테고리 | 선택 안 함 | "카테고리를 선택해주세요" 에러 | ⬜ |
| 필수 필드 - 난이도 | 선택 안 함 | "난이도를 선택해주세요" 에러 | ⬜ |
| 제목 길이 제한 | 201자 입력 | "제목은 200자 이하" 에러 | ⬜ |
| 설명 길이 제한 | 5001자 입력 | "설명은 5000자 이하" 에러 | ⬜ |
| 썸네일 URL - 잘못된 형식 | "invalid-url" 입력 | "유효한 URL을 입력해주세요" 에러 | ⬜ |
| 썸네일 URL - 빈 값 | 빈 값으로 제출 | null로 저장, 에러 없음 | ⬜ |
| 썸네일 URL - 유효한 URL | "https://example.com/img.jpg" | 정상 제출 | ⬜ |

## 4. 폼 제출 및 API 호출

| 시나리오 | 검증 항목 | 예상 결과 | 상태 |
|---------|----------|-----------|------|
| 정상 제출 | 모든 필수 필드 입력 후 제출 | POST /instructor/courses 호출 | ⬜ |
| 요청 본문 | API 페이로드 확인 | title, description, category, difficulty, thumbnailUrl | ⬜ |
| 201 Created | 정상 응답 | 성공 토스트 + 리다이렉트 | ⬜ |
| 리다이렉트 | 성공 후 | `/instructor/courses/:courseId`로 이동 | ⬜ |
| 401 에러 | 인증 만료 | "인증 필요" 에러 토스트 | ⬜ |
| 403 에러 | 권한 없음 | "강사 권한 필요" 에러 토스트 | ⬜ |
| 422 에러 | 검증 실패 | 구체적 에러 메시지 토스트 | ⬜ |
| 500 에러 | 서버 에러 | "코스 생성 실패" 에러 토스트 | ⬜ |
